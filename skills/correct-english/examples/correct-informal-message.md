# Example: Correcting an Informal Chat Message

**Scenario**: The user pastes a casual chat message with several spelling, grammar, and punctuation errors.
The capability fixes the errors and standardizes informal forms while keeping the message's casual tone.

**Applies**: **correct-english-text**

## Input

> hey can u send me the report bfore tomorow? i think theirs a few mistaeks in it and i wanna fix them b4 the meeting

## Output

> Hey, can you send me the report before tomorrow? I think there are a few mistakes in it, and I want to fix them before the meeting.
