# Idea Evaluation

Used by **evaluate-ideas** to score and prioritize the surviving candidates. Risks and trade-offs belong to **challenging-ideas.md**.

## Dimensions

Score each idea 0–2 on every dimension; show the number and one line of evidence.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Value | Serves no stated goal | Serves a goal indirectly | Directly serves a stated goal |
| Feasibility | Needs resources you lack | Possible with a stated trade-off | Doable now with current means |
| Differentiation | Commodity | Some edge | Clearly distinct from alternatives |
| Scope | Too large for the round | Needs trimming | Right-sized |
| Impact | Few people affected | Moderate reach | Broad, lasting effect |

## Method
- Score the ideas you will recommend (2–4) in full; give every other candidate one line and its reason.
- Give each score one line of evidence, never a bare label.
- Add the totals and a one-line recommendation.

## Prioritization
- **Effort vs impact**: do high-impact, low-effort first; plot the rest on a 2×2.
- **MoSCoW**: label each candidate Must / Should / Could / Won't, and say "do now / do next / optional / not this round" in plain words.
