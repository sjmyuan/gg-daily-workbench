# Writing Styles and Article Structure

## Four styles

| Style | Structure | Best fit |
|---|---|---|
| Deep analysis | Problem → Analysis → Conclusion | Clear thesis, rigorous argument, strong evidence |
| Narrative story | Situation → Conflict → Insight | Real experience, story arc, insight through experience |
| Practical guide | Problem → Method → Steps → Result | Clear steps, hands-on, actionable |
| Opinion / commentary | Viewpoint → Evidence → Rebuttal → Conclusion | Strong stance, unique angle, provokes thought |

Recommend one style per article and let the user confirm before composing.

## Article structure

- Title: 2–3 candidates, each with a different angle (question, conclusion, value).
- Intro: hook sentence + background + value promise (the core question, what the reader gains).
- Body: one core point per section, each with examples or analysis and a subheading.
- Conclusion: distill the insight, then give a direction or an open thought.
- Transitions: natural logical links between sections, no abrupt jumps.

## Subheadings

Two shapes the author uses, both acceptable: a plain noun phrase ("第一次部署的影响最为明显", "系统指令模板") or a question ("为什么要提高AI编程助手的使用率？", "知识和案例分享为啥有效？").

Before committing to question headings, two conditions:

1. **Each question must name what its section actually answers.** A question whose answer is not the section's content reads as filler — the author rejected "这四条是从哪来的" on exactly this ground. Chain check: read only the headings, top to bottom; they should form a sequence of questions the article answers in order.
2. **After renaming a heading, re-read the section's first sentence.** If it repeats the heading verbatim ("汇报该多勤？" followed by "汇报该多勤，两个方向我都吃过亏"), rewrite the sentence. The same check applies to a heading and the first sentence of the summary: do not restate the same list in the same words.

## Sequels

When the article continues a previously published post, handle the relationship explicitly: link the previous post in the intro, keep shared terms identical, and link back once more in the closing section. Cite what the earlier post established instead of re-arguing it.
